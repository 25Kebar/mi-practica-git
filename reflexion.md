PREGUNTA 1: Importancia de git status
Explica con tus palabras por que es importante hacer git status ANTES de hacer un add y DESPUES de un add. ¿Qué información te salva de cometer errores?
R/ta: El Git Status es importante debido a que nos muestra los archivos que están en nuestra carpeta donde en el cual se revela la información de los archivos que se han hecho cambios, archivos que se han agregado y archivos nuevos, sin hacer el status, no podemos hacer el git add debido a que no permitimos que se revele la información de los archivos mas importantes para despues enviarlos
PREGUNTA 2: Orden de pull y push
Explica con tus palabras por que es importante hacer git status ANTES de hacer un add y DESPUES de un add. ¿Que información te salva de cometer errores?
R/ta: El Git push seria rechazado y mostrara el error con el proposito de proteger su informacion a otra persona, para la proteccion de datos, detecta que el repositorio remoto está más actualizado que tu copia local. Para solucionarlo se requiere usar el comando de git pull para traer el trabajo de otro usuario a la computadora Si yo y otra persona modificaron las mismas líneas de un archivo, Git detectará el conflicto y nos pedirá que decidas qué cambios conservar. Después de elegir y unir correctamente los cambios, guarda el archivo y continúa con el proceso.

Se vuelve a enviar una vez resuelto el conflicto y confirmado el cambio, ejecuta nuevamente git push para enviar la versión actualizada del código al repositorio remoto.
